3. 영상 생성 파이프라인 전면 개편
--------------------------------------------------------

  [AS-IS]
  Playwright 기사 캡처 → 원문 TTS → 자막 한꺼번에 표시

  [TO-BE]
  Gemini 기사 요약 → 키워드 이미지 검색 → 이미지 위에 뉴스 정보 오버레이
  → 요약 TTS → 배경 3초 교체 + 자막 한 줄씩 표시

  상세:

  (신규) article_summarizer.py
  - Gemini로 기사를 3~4문장 요약
  - 각 문장 = 자막 한 줄, TTS 타이밍에 맞춰 표시
  - 실패 시 기사 제목을 fallback으로 사용

  (신규) image_fetcher.py
  - 네이버 이미지 검색 API로 키워드 관련 이미지 다운로드
  - 필요 이미지 수 = 오디오 길이 / 3초 (20초 영상 → 7장)
  - 9:16 비율 중앙 크롭 + 1080×1920 리사이즈
  - 다운로드 실패 대비 여유분(2배) 요청

  (개편) screenshot_capture.py
  - Playwright 전체 페이지 캡처 제거
  - 검색 이미지 배경 + 상단 그라데이션 오버레이 (가독성 확보)
  - 키워드 태그 + 제목(그림자 포함) + 출처 합성
  - 이미지 없을 시 그라데이션 배경 fallback

  (수정) tts_generator.py
  - 입력: 기사 원문 → 요약 문장 리스트
  - 문장 단위 TTS 타이밍(start/end) 유지

  (수정) subtitle_renderer.py
  - 한 문장씩 렌더링 (기존: 전체 텍스트 한번에)
  - 자막 위치 하단 조정 (뉴스카드 제목과 겹침 방지)

  (수정) video_creator.py
  - 새 파이프라인 7단계:
    1) 기사 요약 (Gemini)
    2) TTS 나레이션 (요약 텍스트)
    3) 키워드 이미지 검색 + 뉴스 오버레이 프레임 생성
    4) 배경 3초 교체 + 자막 TTS 타이밍 병합 → 프레임 생성
    5) FFmpeg 영상 조립
    6) 속도 조절
    7) 출력 저장
  - 핵심: _build_timed_frames()
    → 배경 교체 시점(0, 3, 6, 9...)과 자막 교체 시점(TTS)을
      change point로 병합
    → 각 구간마다 (현재 배경 + 현재 자막) 프레임 렌더링
    → 3초마다 배경 이미지 전환, 자막은 TTS 싱크에 맞춰 한 줄씩
