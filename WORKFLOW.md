# Shorts Auto - 워크플로우 가이드

> 마지막 업데이트: 2025-02-11

## 시스템 개요

네이버 뉴스를 수집·분석하여 YouTube Shorts 영상을 자동 생성하고 업로드하는 Flask 웹 애플리케이션.

```
사용자(브라우저) ──── Flask 서버 (app.py, :8080) ──── 외부 서비스
                                                      ├─ 네이버 뉴스 API
                                                      ├─ Edge TTS
                                                      ├─ Playwright (브라우저)
                                                      ├─ FFmpeg
                                                      └─ YouTube Data API
```

## PHASE 1: 뉴스 수집 & 이슈 분석

**API**: `POST /api/fetch-issues`

```
Step 1                          Step 2                       Step 3
뉴스 수집                        이슈 클러스터링                UI 표시
(news_collector.py)             (issue_analyzer.py)

 네이버 뉴스 API                 키워드 추출                   화제 목록
 ┌──────────────┐               (한글 2글자 이상,             (최대 5개 토픽)
 │ 검색 키워드:   │               불용어 제거)                  ┌──────────┐
 │ 정치, 국회,   │──▶ 기사 목록 ──▶                            │ □ 이슈 1  │
 │ 대통령, 여당, │   (중복 제거,       ▼                       │ □ 이슈 2  │
 │ 야당          │    7일 이내)                                │ □ 이슈 3  │
 └──────────────┘              유사도 기반 그룹핑              │ □ 이슈 4  │
                               (Jaccard ≥ 0.15)              │ □ 이슈 5  │
 각 키워드 100건 검색                   ▼                      └──────────┘
                               기사 수 기준 랭킹
                               (많이 다뤄진 순)
```

**핵심 로직:**
- `collect_news()` → 5개 키워드 × 100건 = 최대 500건 수집 (중복·기한 필터링)
- `analyze_issues()` → 키워드 유사도로 클러스터링 → 상위 5개 토픽 반환
- 각 토픽: 제목(상위 키워드 3개), 요약(가장 짧은 기사 제목), 관련 기사 목록

## PHASE 2: 영상 생성 파이프라인

**API**: `POST /api/generate-shorts` → `job_id` 반환 (백그라운드 스레드 실행)
**상태 조회**: `GET /api/generation-status/<job_id>` (2초 간격 폴링)

```
                        video_creator.py (_pipeline)
                        ================================

  옵션 입력                   기사 수 결정
  ┌──────────────┐           ┌─────────────────────┐
  │ 영상길이      │           │ 10-20초 → 기사 1개   │
  │ 자막위치      │──────────▶│ 20-30초 → 기사 2개   │
  │ 영상속도      │           │ 30-40초 → 기사 3개   │
  └──────────────┘           └─────────┬───────────┘
                                       │
                                       ▼
  ┌────────────────────────────────────────────────────────────────┐
  │                                                                │
  │  Step 1: 스크린샷 캡처 (0~20%)          screenshot_capture.py  │
  │  ┌──────────────────────────────────────────────────────┐      │
  │  │ Playwright로 기사 URL 접속                             │      │
  │  │  → 스크린샷 촬영 (1080×1920 리사이즈)                   │      │
  │  │  → 출처 바 추가 (하단 반투명)                            │      │
  │  │  → 실패 시: 대체 이미지 생성 (제목 + 출처 텍스트)         │      │
  │  └──────────────────────────────────────────────────────┘      │
  │                          │                                     │
  │                          ▼                                     │
  │  Step 2: TTS 나레이션 (20~40%)              tts_generator.py   │
  │  ┌──────────────────────────────────────────────────────┐      │
  │  │ Edge TTS (ko-KR-InJoonNeural 음성)                    │      │
  │  │  → 기사 제목 + 설명(80자) 으로 나레이션 텍스트 구성      │      │
  │  │  → MP3 음성 파일 생성                                   │      │
  │  │  → SentenceBoundary 이벤트로 자막 타이밍 추출            │      │
  │  └──────────────────────────────────────────────────────┘      │
  │                          │                                     │
  │                          ▼                                     │
  │  Step 3: 자막 렌더링 (40~60%)           subtitle_renderer.py   │
  │  ┌──────────────────────────────────────────────────────┐      │
  │  │ PIL/Pillow로 이미지 위에 자막 오버레이                   │      │
  │  │  → 위치: 상단(200) / 중간(860) / 하단(1600)             │      │
  │  │  → 반투명 배경 박스 + 흰색 텍스트                        │      │
  │  │  → 한글 자동 줄바꿈                                     │      │
  │  └──────────────────────────────────────────────────────┘      │
  │                          │                                     │
  │                          ▼                                     │
  │  Step 4: 영상 조립 (60~80%)                                    │
  │  ┌──────────────────────────────────────────────────────┐      │
  │  │ FFmpeg concat demuxer                                 │      │
  │  │  → 오디오 파일 병합 (여러 기사인 경우)                    │      │
  │  │  → 이미지별 표시 시간 = 해당 오디오 길이                  │      │
  │  │  → 이미지 슬라이드쇼 + 오디오 합성                       │      │
  │  │  → 출력: 1080×1920 MP4 (libx264, yuv420p)              │      │
  │  └──────────────────────────────────────────────────────┘      │
  │                          │                                     │
  │                          ▼                                     │
  │  Step 5: 속도 조절 (80~95%)                                    │
  │  ┌──────────────────────────────────────────────────────┐      │
  │  │ FFmpeg filter_complex                                 │      │
  │  │  → 느리게: 0.8x / 중간: 1.0x / 빠르게: 1.2x / 초고속: 1.5x│     │

  │                          │                                     │
  │                          ▼                                     │

  │  ┌──────────────────────────────────────────────────────┐      │
  │  │ output/shorts_YYYYMMDD_HHMMSS.mp4 로 이동              │      │
  │  │ temp 디렉토리 정리                                      │      │
```

## 외부 의존성

| 서비스/도구 | 용도 | 설정 |
|---|---|---|
| **네이버 뉴스 API** | 뉴스 기사 수집 | `.env`에 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` |
| **Edge TTS** | 한국어 음성 합성 (무료) | 음성: `ko-KR-InJoonNeural` |
| **Playwright** | 기사 페이지 스크린샷 | `playwright install chromium` 필요 |
| **FFmpeg** | 영상 조립, 속도 조절 | 시스템에 설치 필요 |
| **YouTube Data API v3** | 영상 업로드 | `client_secret.json` + OAuth 인증 |
| **Pillow (PIL)** | 이미지 자막 렌더링 | 한글 폰트 자동 탐색 |

## 옵션 설정값

### 영상 길이 → 기사 수
| 영상 길이 | 사용 기사 수 |
|---|---|
| 10~20초 | 1개 |
| 20~30초 (기본) | 2개 |
| 30~40초 | 3개 |

### 속도 배율
| 옵션 | 배율 |
|---|---|
| 느리게 | 0.8x |
| 중간 (기본) | 1.0x |
| 빠르게 | 1.2x |
| 매우 빠르게 | 1.5x |

### 영상 사양
- 해상도: **1080 × 1920** (9:16 세로, YouTube Shorts 규격)
- 코덱: libx264, yuv420p
- 출력 형식: MP4
