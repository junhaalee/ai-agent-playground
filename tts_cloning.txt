========================================
 TTS 음성 클로닝 옵션 비교 (2026.02.22)
========================================

목적: 내 목소리와 비슷한 TTS 음성으로 쇼츠 자막 나레이션 생성
현재 환경: macOS (Apple Silicon), edge-tts (ko-KR-HyunsuNeural) 사용 중


──────────────────────────────────────
1. ElevenLabs (클라우드 API)
──────────────────────────────────────

[장점]
- 음성 샘플 1~3분만 녹음하면 즉시 클로닝 완료
- 한국어 지원, 품질 최상급
- API 호출 한 번으로 끝 (코드 연동 매우 간단)
- 로컬 GPU 불필요
- 생성 속도 빠름 (1~2초)

[단점]
- 유료: 월 $5 (30분 생성) ~ $22 (100분 생성)
- 외부 서비스 의존 (서버 장애 시 사용 불가)
- 생성 분량 제한 있음 (플랜별 월 한도)

[난이도] 쉬움


──────────────────────────────────────
2. GPT-SoVITS (오픈소스, 로컬)
──────────────────────────────────────

[장점]
- 완전 무료
- 1분 음성으로 few-shot 클로닝 가능
- 한국어 품질 좋음
- 학습 후 로컬에서 무제한 생성

[단점]
- GPU 권장 (NVIDIA CUDA 기준 최적화)
- Mac MPS 지원 불안정, CPU는 매우 느림
- 설치 과정 복잡 (의존성 많음)
- 학습에 30분~1시간 소요 (GPU 기준)
- 모델 크기 큼 (~2GB+)

[난이도] 중간~어려움


──────────────────────────────────────
3. Coqui XTTS v2 (오픈소스, 로컬)
──────────────────────────────────────

[장점]
- 완전 무료
- 학습 없이 6초 레퍼런스 오디오로 즉시 클로닝
- pip install TTS 한 줄로 설치
- 한국어 지원

[단점]
- 모델 크기 ~1.8GB (첫 실행 시 다운로드)
- GPU 없으면 느림: CPU로 1문장 생성에 10~30초
- Mac MPS 지원 불안정 (에러 발생 가능)
- 한국어 품질은 ElevenLabs보다 떨어짐
- 쇼츠 1개 (10~15문장) 생성 시 CPU 기준 5~10분 소요

[난이도] 쉬움


──────────────────────────────────────

──────────────────────────────────────

──────────────────────────────────────
현실적 결론 (Mac 환경)
──────────────────────────────────────

Mac (Apple Silicon) 환경에서는 GPU(CUDA) 가속을 쓸 수 없기 때문에
로컬 오픈소스 모델(GPT-SoVITS, Coqui XTTS v2)은 속도와 안정성 면에서 실용적이지 않음.

- GPT-SoVITS: Mac MPS 불안정, CPU로는 비현실적으로 느림
- Coqui XTTS v2: 돌아가긴 하지만 쇼츠 1개 만드는데 5~10분 대기
- ElevenLabs: Mac 환경과 무관하게 API 호출이므로 가장 현실적

→ 음성 클로닝을 실제로 적용하려면 ElevenLabs (월 $5)가 유일하게 실용적인 선택.
→ 무료로 하려면 NVIDIA GPU가 있는 별도 PC 또는 클라우드 GPU (Colab 등) 필요.
→ 당장은 도입하지 않고, 필요 시 ElevenLabs 우선 검토.
